02 / THE ACTUAL UNISWAP INTERFACESOFFICIAL OPEN-SOURCE EVIDENCE

Two mechanisms, two different calls.

ALLOWANCE

PermitSingle / PermitBatch

Use permit(address owner, PermitSingle|PermitBatch, bytes signature), then a separate transferFrom. The signed spender should match the contract that later invokes transferFrom; a relayer may submit the original permit.

SIGNATURE

PermitTransferFrom

Use permitTransferFrom(permit, transferDetails, owner, signature). Signed permission includes token/amount, nonce and deadline; actual caller is incorporated in contract authorization, while transferDetails.to is supplied by the call.

SEPARATE LAYERS

ERC-20 → Permit2

The token's ERC-20 approval of the Permit2 contract differs from the spender's Permit2-level permission. A checkbox or copied JSON does not independently prove either live allowance.

UNKNOWN
